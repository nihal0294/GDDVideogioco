# Sinergia

La sinergia è una meccanica unica che influisce sulle specie di Aster in possesso del giocatore. Una sinergia si attiva quando due o più membri della stessa specie si trovano nel party. Diverse specie producono diversi effetti. Questi effetti non sono permanenti ma perdurano per il corso di una battaglia. Alcuni esempi di effetti sono: 

- Potenziare una statistica casuale o precisa
- Infliggere più danni
- Diminuire i danni nemici
- Curarsi ogni tot turni
- Evocare un Pokémon specifico se si ha uno slot vuoto
- Utilizzare più attacchi in un turno

Le sinergie sono visibili in un menù fuori dalla battaglia. È possibile fondere più sinergie di determinati tipi per creare diversi effetti. Una lista possibile di specie sarà: Dinosauro, anfibio, acquatico, terrestre, sintetico, bestiale, aero, fatato, insetto, freddo, caldo, etereo, cristallo, drago, fossile, mitico, leggendario
