# Mappe

Ogni mappa deve avere una propria cartella, per esempio:

```text
starting_village/
|-- starting_village.tscn
|-- starting_village.gd
`-- navigation.tres
```

Gli asset grafici usati dalla mappa vanno in `assets/maps/`; layout, sorgenti e immagini di riferimento vanno in `assets/references/maps/`.
