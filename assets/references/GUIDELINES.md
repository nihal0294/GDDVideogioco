# Riferimenti visivi

Qui vanno concept art, bozze, moodboard e layout di riferimento, organizzati per personaggi, Astral, ambienti e mappe.

Questi file non devono essere referenziati dalle scene Godot. L'intera cartella `assets/references/` è esclusa dall'importazione attraverso `.gdignore`.

Gli asset definitivi utilizzati dal gioco vanno nelle categorie runtime di `assets/`, mentre scene e script appartengono a `game/`.
